Run `dotnet run -c Release --project Tools/MainMenuTerrainCheck/MainMenuTerrainCheck.csproj` from the repository root.

The check executes the production layout math against Unity.Mathematics without loading UnityEngine or starting Unity. It checks 36 combinations of seed, size and camera yaw for valid heights, normalized paint weights, a flat house site, a continuous painted road and driveway, near-camera relief and grass exclusion. It also checks deterministic seeds and writes approximate top-down previews under `.codex/MainMenuTerrainCheck/`.

The Editor tool is available at `Tools > Dustborn > Main Menu Terrain` with the MainMenu scene active. Each generation creates independent assets under `Assets/_Dustborn/Generated/MainMenu/`. The camera stays in place. The empty House Site object marks the flat footprint. Save the scene after reviewing the generated terrain. Undo restores previous terrain visibility and removes the new scene objects; generated assets remain available.

The generator lives under the Editor-only WorldGen assembly. The built player uses native Terrain, TerrainCollider, Terrain Details and the asset's RepetitionlessTerrain component. The material explicitly binds every Terrain alphamap, the layer count and the shader capacity before being saved; the Repetitionless component keeps its material instance synchronized with Terrain painting. Grass textures are baked from the source biome cards and color masks; native Terrain supplies billboard rendering and wind. Shore plants are excluded because this scene has no generated water.

To restore an existing generated Terrain, select its Terrain object and run `Tools > Dustborn > Repair Selected Main Menu Terrain`. The same action is available as `Restore Road And Remove Burnt Grass` in the generator window. It creates a separate TerrainData and material, preserves the sculpted heights and remaining grass maps, regenerates road and ground paint and removes the generated Burnt_Grass prototypes. RepetitionlessTerrain is attached or updated. Every ground layer enables randomized texture rotation and scaling. Material finalization also runs after the package's deferred setup so its initial medium-quality noise keyword cannot override the configured dynamic noise.

Defaults use a 1.4 grass density multiplier, 1.2 grass size multiplier and 1.2 m surface unevenness. Only the forest biome supplies grass; burnt ground layers remain, with no burnt grass prototypes generated. Grass patches retain a sparse base cover between dense clumps. The house site remains flat and clear; the road profile smooths the surrounding relief. Existing window settings migrate to these defaults once after this update. Regenerate the terrain to apply all changes to saved output.

TerrainData is created before map edits. Ground painting is applied after all material and grass texture imports, synchronized from GPU to CPU, and saved with its control textures marked dirty. The command force-reimports the TerrainData and compares saved paint samples with the generated weights before placing it in the scene. This catches the previously observed saved map containing only a solid Forest_Base layer and empty road controls.

Five Burst IJobParallelFor jobs build heights, paint weights, shared grass surface masks, all grass instance maps and recolored grass pixels. The math layout contains no managed references. Terrain and AssetDatabase operations stay on the Editor thread. Job completion always precedes buffer disposal, including cancellation and failures. Managed Terrain upload buffers are copied in bulk and reused for grass layers. Native Terrain.GetSteepness calls are replaced with bilinear height sampling and finite differences, including one-sided differences at the boundary.

The offline check links the production job Execute methods with managed NativeArray substitutes; it does not run Unity's scheduler or Burst compiler. It compares height and paint math with a frozen pre-optimization reference, checks job indexing and deterministic row order, verifies slope sampling on a plane, and checks grass texture channels and alpha. Grass positions use per-cell hashes, so a regeneration changes their arrangement while remaining reproducible for a seed.

The benchmark reports median managed height-math timings over five runs at 257 x 257 samples. It excludes Burst and Unity asset creation. The actual Editor command logs separate timings for heights, Terrain upload, painting and save validation, Repetitionless packing, grass and texture imports, and total generation.
