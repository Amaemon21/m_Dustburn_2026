# Dustborn Water Stamps

Технический пак масок для процедурной генерации рек, озёр и прудов.

## Формат
- 1024×1024
- RAW16 little-endian (`uint16`, без заголовка)
- PNG16 grayscale
- Чёрный = отсутствие влияния
- Белый = максимальная глубина / центральная часть русла или водоёма
- Серый = плавный переход к берегу

## Состав
- 16 речных штампов
- 8 озёрных штампов
- 2 пруда
- `manifest.json` с типом, рекомендуемым размером, глубиной, шириной берега и сокетами рек.

## Для рек
В `manifest.json` есть `entry`, `exit`, а для развилок/слияний — `branches`.
Координаты нормализованы от 0 до 1 в локальном UV штампа.

## Важно
Эти маски предназначены для гибридной схемы:
гидрология выбирает логичный маршрут и высоты, штамп задаёт красивую форму,
после чего рельеф вырезается и вода строится по итоговой маске.

Не используйте PNG как цветную текстуру; это height/mask data.
