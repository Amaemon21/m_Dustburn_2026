# 20 штампов ландшафта для процедурного генератора

Это числовые карты смещения высоты, а не изображения с нарисованными тенями. Все формы созданы процедурно для этого набора; сторонние текстуры, файлы из 7 Days to Die и готовые DEM не использовались.

## Содержимое

- heightmaps_png16/ — 20 отдельных одноканальных PNG, 1024 × 1024, 16 бит.
- heightmaps_raw16/ — те же 20 карт в RAW16. Это альтернативный формат, а не ещё 20 разных штампов.
- previews/ — изображения с освещением ТОЛЬКО для просмотра. Их нельзя подавать в генератор как высоту.
- catalog_preview.jpg — общий каталог.
- manifest.json — параметры, режим применения, пути и контрольные суммы.
- validation_report.json — результаты проверки формата и данных.

## Формат и смысл значений

Диапазон данных: 0 … 65535. Нормализованное значение s = value / 65535.0.
Чёрный (0) всегда означает НУЛЕВОЕ изменение исходной земли. Белый (65535) означает максимальное смещение. Серый 32768 НЕ является нейтральной высотой.
PNG не содержит alpha, sRGB или гамма-коррекции. Читайте значения как линейные числовые данные и сохраняйте 16 бит при декодировании. Просмотрщик может отображать лишь 256 тонов, но сами файлы содержат 16-битные значения.
RAW: uint16, little-endian, без заголовка, ровно 2 097 152 байта. Сначала верхняя строка PNG, внутри строки — слева направо. PNG и RAW совпадают побитно после декодирования.

## Применение к вашему H(x, z)

1. Выберите центр штампа и его физический размер по X/Z.
2. Переведите точку мира в локальные UV штампа с учётом выбранного поворота. Центр штампа — UV (0.5, 0.5).
3. Вне диапазона UV [0,1] влияние равно нулю. Не используйте Repeat.
4. Считайте высоту билинейной интерполяцией.
5. Примените смещение в метрах:

```text
s = SampleHeight16(uv) / 65535.0
если operation = add:       H_new = H_old + amplitude_m * s
если operation = subtract:  H_new = H_old - amplitude_m * s
```

Карты 15–18 — глубина вырезаемой области: белое в них означает самое глубокое место, а не вершину. Все остальные карты прибавляют высоту.
Штампы 11–13 имеют пониженный центр относительно окружающего горного обода, но целиком работают как положительное смещение: их центр не уходит ниже исходной земли. Для углубления ниже основания дополнительно примените вычитающий штамп.
Краевой спад уже встроен в данные. Все четыре внешние границы точно равны нулю; есть минимум 24 нулевых пикселя от каждого края и плавная переходная зона. Не умножайте карту на вторую круговую маску по умолчанию — это уменьшит подножие и изменит форму.
Краевой спад предотвращает ступеньку на границе штампа, но не исправляет швы самого чанкового генератора. В соседних чанках используйте одни и те же мировые координаты семплирования.

## Координаты и масштаб

В файлах u растёт слева направо, v — сверху вниз. Рекомендуемое соглашение: local +X совпадает с ростом u, local +Z — с ростом v. Превью ориентировано так же. Если ваш загрузчик переворачивает изображение по вертикали, исправьте это один раз в импорте.
Размер карты в пикселях не задаёт её размер в метрах. Размер пятна и амплитуда независимы. Значения manifest.json — стартовые настройки, а не обязательные размеры.
Для базового RWG сначала создайте спокойный фоновый рельеф, затем применяйте эти штампы. При простом сложении нескольких гор высоты суммируются — контролируйте перекрытия и вертикальный диапазон мира.
Это локальные штампы, а не полные карты мира. Набор содержит открытые поверхностные формы; карты высот не кодируют пещеры, тоннели и нависающую геометрию.

## Минимальный пример чтения RAW на Python

```python
import numpy as np
height = np.fromfile("heightmaps_raw16/01_alpine_peak.raw", dtype="<u2").reshape(1024, 1024)
displacement_m = height.astype(np.float32) / 65535.0 * 260.0
```

При чтении из C# соответствующий тип одного отсчёта — ushort; порядок байтов little-endian. Избегайте преобразования в 8-битный Color32 перед использованием высоты.

## Проверки и ограничения

Для каждой карты проверены размер, реальная 16-битность PNG, диапазон, нулевой край, совпадение PNG и RAW и контрольные суммы. Предпросмотр проверен визуально.
Интеграция с вашим конкретным генератором не проверялась: его формат импорта не предоставлен. RAW16 — наиболее прямой вариант чтения числовых данных без вмешательства текстурного импорта.
